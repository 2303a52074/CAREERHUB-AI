# CareerHub AI – Career and Placement Assistant

CareerHub AI is a project developed to help students with their career preparation. It brings career guidance, resume analysis, interview practice, job searching, coding practice, and learning plans together in one platform.

## Features

- Career Assessment
- AI Career Assistant
- Skill Gap Analysis
- Career Roadmap
- Daily Preparation Plan
- Resume Analyzer
- Job Description Analyzer
- Live Job Matching
- Application Tracker
- Technical and HR Mock Interviews
- MCQ, Voice and Video Interviews
- Coding Practice with 100 DSA Problems
- Python, Java, C++ and JavaScript Execution
- LeetCode Profile Link
- Learning Resources
- Progress Analytics

## Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JWT
- AI: Google Gemini API
- Job API: Arbeitnow
- Code Execution: Docker

## Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/2303a52074/CAREERHUB-AI.git
cd CAREERHUB-AI
```

**2. Install dependencies**

```bash
npm install
```

**3. Configure environment variables**

Create your environment file using `.env.example` and add your own credentials.

**4. Start MongoDB and Docker**

Make sure both services are running.

**5. Run the project**

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.
